# Excel Interactive Dashboard

An interactive Excel dashboard built from a public dataset as part of a timed, 3-hour assignment. The project covers the full workflow: importing data, cleaning it, analyzing it with PivotTables and formulas, visualizing it, and presenting everything in an interactive dashboard.

## Assignment Guidelines

| Sr. No. | Guideline |
|---------|-----------|
| 1 | Time limit: 3 hours |
| 2 | Choose any dataset from Kaggle / UCI ML Repository |
| 3 | Create an interactive dashboard |
| 4 | Complete tasks in the order listed |
| 5 | Save work every 15 minutes |
| 6 | Submit final file as `YourName_ExcelDashboard.xlsx` |

## Task Breakdown

| Sr. No. | Task | Skills Tested | Time Estimate (min) | Weightage |
|---------|------|---------------|---------------------|-----------|
| 1 | Dataset Selection & Import | Data import, initial cleaning | 15 | 5% |
| 2 | Data Cleaning & Preparation | Remove duplicates, handle missing values, format data types | 25 | 10% |
| 3 | Create Pivot Tables | Data analysis, summarization | 30 | 15% |
| 4 | Advanced Formulas | VLOOKUP, INDEX-MATCH, IF conditions, nested functions | 35 | 15% |
| 5 | Data Visualization | Charts, conditional formatting | 40 | 20% |
| 6 | Interactive Dashboard | Slicers, timeline, dynamic ranges | 45 | 25% |
| 7 | Documentation | Sheet organization, naming conventions, instructions | 20 | 10% |
